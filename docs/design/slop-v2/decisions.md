The source `.impeccable.md` is design context, not independent product or economic authority.

Lead with the promise and useful work: editorial hero, lined project index, compact accepted-outcome ranking and a short process. Avoid repeated rounded dashboards or decorative charts; evidence and comparison determine whether a chart earns space. Show the header mark and account control with points beside the far-right avatar; group Product, Records and Community in the orange footer. Inverse areas are intentional surfaces within this direction, not an unapproved alternate theme.

The source's consolidated Account, shared standings, project form fields, public Funding Records versus payout workspace, expandable receipt/evidence patterns and archive filters are reuse candidates. Preserve their domain inputs; presentation families do not justify rewriting financial logic. ## Prototype and review boundaries

Provide complete route frames for all 17 source page families at four primary canvases, then meaningful state variants and connected journeys. The state matrix includes route loading, successful empty, stale, invalid, denied, unavailable, failed and ready; project monthly/external/paused/archived/restricted; signed-out/in account; invalid/saved/pending wallets; proposal validation/lookup/draft; review/scheduled/unclaimed/held/paid cycle examples. Shared component specimens supplement route-specific placement, copy and next actions; specimens alone do not prove full state coverage.

Prototype paths require return links, cancellation and recovery as well as happy paths. Link every simulated success to the dependency it assumes. Parent evidence should report actual frame/prototype counts, screenshots and visual/structural gaps instead of declaring completion from planned counts. Figma interaction cannot establish real OAuth, wallet signing, permissions, clipboard/download bytes, screen-reader semantics, console/network cleanliness, chain finality or deployment availability.

The later implementation needs the repository release gate and exact tested head with desktop/mobile, keyboard, zoom, accessibility, copy/download/GitHub links, console/network logs and uploaded walkthrough evidence. This design task does not advance the MVP phase or assert provider/financial activation.
